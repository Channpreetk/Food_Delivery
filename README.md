# Food Delivery Business Analytics Dashboard

An interactive Business Analytics dashboard built using Power BI to analyze food delivery operations, customer behavior, restaurant performance, revenue, and delivery efficiency.

## Project Overview

This project analyzes food delivery order data and converts it into interactive business insights using Power BI.

The dashboard covers:
- Overall business performance
- Customer analytics
- Restaurant performance
- Delivery and operational efficiency
- Advanced business insights

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Microsoft Excel
- Git & GitHub

## Dashboard Pages

### 1. Executive Overview
Provides a high-level view of key business metrics such as:
- Total Orders
- Total Revenue
- Average Order Value
- Total Customers
- Total Restaurants

### 2. Customer Analytics
Analyzes customer activity, repeat customers and ordering behavior.

### 3. Restaurant Performance
Analyzes restaurant ratings, votes, revenue and restaurant-level performance.

### 4. Delivery & Operations
Analyzes delivery time, late deliveries and operational performance.

### 5. Advanced Insights
Provides additional analytical views using DAX measures and time-based analysis.

### 6. Business Insights
Additional business-focused analysis created as part of the project customization.

Key KPIs include:
- Delivered Revenue: 218K
- Delivered Revenue %: 80.85%
- Cancellation Rate: 7.95%
- On-Time Delivery %: 52.60%

## Data Model

The Power BI data model contains four main tables:

- Customers
- Orders
- Restaurants
- DateTable

Relationships were created between customer, restaurant and date dimensions and the Orders fact table.

## Key Business Analysis

The dashboard helps analyze:

- Revenue generated from delivered orders
- Order cancellation rate
- On-time delivery performance
- Customer repeat behavior
- Restaurant performance
- Delivery trends over time
- Restaurant cost and rating relationships

## Custom Analysis

Additional DAX measures were created to extend the initial dashboard analysis, including:

- Delivered Revenue
- Delivered Revenue %
- Cancellation Rate
- On-Time Delivery %

These measures were used to create additional business-focused insights and visualizations.
